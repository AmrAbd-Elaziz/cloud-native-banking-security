# Cloud-Native Banking Security

A hands-on security architecture project demonstrating threat modeling,
cloud security, Kubernetes hardening, Infrastructure as Code scanning,
risk assessment and PCI DSS security control mapping.

> Security notice: This project represents a fictional banking environment
> created exclusively for authorized security training. It contains no real
> customer data, production credentials or deployable banking services.

## Project Objective

Design and assess a fictional cloud-native banking platform that supports:

- Customer authentication
- Account information
- Internal money transfers
- Payment processing
- Transaction history
- Security monitoring and audit logging

The project documents the complete security engineering lifecycle:

1. Define architecture and critical assets
2. Identify trust boundaries and data flows
3. Perform STRIDE threat modeling
4. Create a risk register
5. Review vulnerable cloud and Kubernetes configurations
6. Implement security remediation
7. Map controls to PCI DSS requirements
8. Automate security testing in GitHub Actions

## Planned Security Testing

- Terraform and IaC scanning
- Kubernetes manifest scanning
- Container configuration assessment
- Secrets scanning
- Policy-as-Code validation
- Cloud IAM review
- Kubernetes RBAC review
- Network segmentation validation
